# 📊 Dashboard Interativo de Nutrição e Progresso

Este projeto foi desenvolvido para servir como um **dashboard interativo** voltado para acompanhamento nutricional e progresso físico.  
A aplicação permite visualizar dados básicos, plano alimentar detalhado, tabelas interativas de refeições, suplementação recomendada, dicas finais e gráficos comparativos entre progresso real e metas (força e perda).

---

## 🎯 Funcionalidades:

- Exibição de **dados básicos** do usuário.  
- **Plano alimentar** com detalhamento nutricional.  
- **Tabelas interativas** de acordo com as opções de refeições.  
- **Suplementação recomendada** para apoio ao plano.  
- **Dicas finais** para otimização dos resultados.  
- **Gráfico interativo** comparando progresso real vs meta (força e perda).  

---

## 📂 Estrutura do Projeto:

- **dashboard.py** → Script principal do dashboard.  
- **dashboard_interativo.py** → Versão interativa do dashboard.  
- **dashboard_massa_muscular.py** → Dashboard específico para acompanhamento de massa muscular.  
- **requirements.txt** → Lista de dependências necessárias.
